**한 줄 요약** 코딩 문법을 외우는 수업이 아니라, 내 문제를 말로 설명해 AI와 함께 진짜 서비스를 만들고 세상에 내놓는 8주 과정이에요.

---

## 📣 수업 소개글

### 짧은 버전 (포스터·카드용)

> **"코딩, 몰라도 돼요. 만들고 싶은 게 있으면 돼요."**
> 클로드코드로 8주 동안 내 아이디어를 진짜 웹사이트와 앱으로 만들어 봐요.
> 문법 암기 없음 · 내 문제에서 출발 · 마지막 시간엔 친구·가족 앞 발표

### 긴 버전 (신청 페이지용)

예전에는 앱을 만들려면 몇 년씩 코딩을 배워야 했어요. 지금은 달라요. **클로드코드**는 우리가 한국어로 설명하면 코드를 읽고, 쓰고, 고쳐 주는 AI 도우미예요.

그렇다고 AI가 다 해 주는 건 아니에요. 무엇을 만들지 정하는 일, 좋은 지시를 내리는 일, AI가 틀린 곳을 알아채는 일은 사람이 해야 해요. 이 수업은 바로 그 부분을 훈련합니다.

8주 동안 학생들은 이렇게 해요.

- 우리 반 시간표 앱, 시험 D-day 계산기처럼 **자기 생활 속 불편**을 하나 골라요.
- 클로드코드에게 **정확하게 말하는 법**을 배워요. 말이 정확해질수록 결과물이 좋아져요.
- 만든 것을 **인터넷에 올려** 링크 하나로 누구나 쓰게 만들어 봐요.
- AI가 만든 코드를 **그대로 믿지 않고 확인**하는 습관을 길러요.
- 마지막 시간에 **친구와 가족 앞에서 발표**해요.

**이런 친구에게 맞아요** 중1~고2, 코딩 경험 없음 OK, 만들어 보고 싶은 게 하나라도 있는 친구
**준비물** 노트북(Windows·Mac), 인터넷, 호기심
**정원** 8~12명 (한 명씩 막히는 곳을 봐 줄 수 있는 규모)

## 🗺️ 커리큘럼 한눈에 보기

주 1회 · 회당 120분(실습 중심) · 총 8회

| 회차 | 주제 | 오늘 만드는 것 | 핵심 배움 |
|---|---|---|---|
| 1 | 첫 만남: AI에게 일 시키기 | 나를 소개하는 웹페이지 1장 | 클로드코드가 뭔지, 한국어로 시키면 파일이 생긴다는 경험 |
| 2 | 좋은 지시 쓰기 | 같은 페이지의 3가지 버전 | 목표·조건·예시를 넣어 말하기, 고치며 반복하기 |
| 3 | 세상에 올리기 | 내 주소(링크)가 있는 사이트 | 저장 지점(커밋), GitHub Pages 배포 |
| 4 | 읽고 의심하기 | 일부러 망가뜨린 코드 고치기 | 코드 읽는 눈, AI가 틀리는 순간 알아채기 |
| 5 | 미니 도구 만들기 | 단어장·타이머·퀴즈 중 택1 | 버튼·입력·저장 같은 앱의 기본 부품 |
| 6 | 내 프로젝트 기획 | 한 장짜리 기획서 + 규칙 파일 | 문제 정의, 기능 줄이기, `CLAUDE.md` |
| 7 | 만들고, 써 보게 하고, 고치기 | 프로젝트 1.0 | 사용자 테스트, 피드백 반영 |
| 8 | 발표회와 앞으로 | 발표 + 수료 | 발표, AI 윤리와 안전, 다음 걸음 |

## 📘 회차별 상세

### 1회 첫 만남: AI에게 일 시키기
- **목표** 클로드코드를 켜고 첫 결과물을 본다. "나도 만들 수 있다"는 느낌이 전부예요.
- **활동**
  1. 터미널이 뭔지 5분 설명 (검은 화면은 무서운 게 아니라 "글자로 하는 리모컨").
  2. `나는 OO중학교 2학년이고 축구를 좋아해. 나를 소개하는 웹페이지를 만들어 줘` 로 시작.
  3. 클로드가 파일을 만드는 과정을 같이 읽어 보기.
  4. 브라우저로 열어 보고 친구와 바꿔 구경하기.
- **알아둘 것** 클로드가 "이 명령을 실행해도 될까요?" 하고 물을 때 **읽고 나서 허용**하는 습관을 첫 시간부터 잡아요.

### 2회 좋은 지시 쓰기
- **목표** "예쁘게 해 줘"와 "배경은 어두운 남색, 글자는 흰색, 제목은 크게"의 차이를 체감한다.
- **활동**
  - 같은 주제로 지시를 세 번 바꿔 쓰고 결과 비교하기 (막연한 지시 → 조건 있는 지시 → 예시 포함 지시).
  - 지시 공식: **무엇을 / 누가 쓰는지 / 지켜야 할 조건 / 예시**
  - 마음에 안 들 때 "다시"가 아니라 **무엇이 왜 아쉬운지** 말해 보기.
- **미니 게임** 짝에게 말로만 그림을 설명하고, 짝은 그 설명대로만 그리기. 지시가 모호하면 그림이 달라지는 걸 눈으로 봐요.

### 3회 세상에 올리기
- **목표** 내 사이트가 `내이름.github.io` 주소로 열린다.
- **활동**
  - 저장 지점(커밋)을 게임의 "세이브 포인트"에 비유해 이해하기.
  - 클로드에게 맡길 일과 내가 직접 할 일 나누기 (계정 만들기·로그인은 직접).
  - 배포하고 폰으로 내 사이트 열어 보기. 이게 은근히 감동이에요.
- **주의** 개인정보(실명, 학교 이름, 사진, 전화번호)는 올리지 않는 규칙을 이 시간에 정해요.

### 4회 읽고 의심하기
- **목표** AI도 틀린다는 걸 알고, 틀린 곳을 찾는 눈을 기른다.
- **활동**
  - 강사가 일부러 버그를 넣은 코드를 나눠 주고 "뭐가 이상한지" 찾기.
  - 클로드에게 "이 코드를 한 줄씩 설명해 줘" 시키고, 설명이 실제 동작과 맞는지 직접 실행해 확인.
  - 클로드가 자신 있게 틀린 사례 보여 주기. **자신 있게 말한다 ≠ 맞다.**
- **한 줄 규칙** "만들었다"가 아니라 "돌려 봤다"까지 해야 끝.

### 5회 미니 도구 만들기
- **목표** 버튼, 입력칸, 저장 같은 앱의 기본 부품을 써 본다.
- **택1 과제** 영어 단어장 / 공부 타이머 / 5문제 퀴즈 / 용돈 기록장
- **활동** 기능을 **하나씩** 추가하며 매번 실행해 보기. 한꺼번에 시키면 어디서 깨졌는지 알 수 없어요.
- **개념 맛보기** 입력 → 처리 → 출력, 새로고침해도 남아 있게 저장하기.

### 6회 내 프로젝트 기획
- **목표** "무엇을 만들까"를 한 장으로 정리한다.
- **활동**
  - 기획서 양식: 누가 쓰나 / 어떤 불편이 있나 / 꼭 필요한 기능 3개 / 하지 않을 것
  - **기능 줄이기 훈련** 욕심을 반으로 줄이는 연습. 8주 안에 끝나는 크기가 좋은 크기예요.
  - `CLAUDE.md`에 프로젝트 규칙 적기 (예: "한국어로 설명해 줘", "내 허락 없이 파일을 지우지 마").
- **강사 팁** 주제가 안 떠오르는 학생에게는 "이번 주에 짜증났던 일 3가지"부터 물어보세요.

### 7회 만들고, 써 보게 하고, 고치기
- **목표** 프로젝트 1.0을 완성하고 다른 사람에게 써 보게 한다.
- **활동**
  - 전반 60분 구현 (막히면 클로드에게 상황을 설명하고, 그래도 막히면 강사 호출).
  - 후반 60분 **사용자 테스트**: 짝에게 설명 없이 쓰게 하고, 어디서 헤매는지 말없이 관찰.
  - 발견한 문제 2개를 골라 고치기.
- **포인트** 만든 사람은 쉽다고 느끼고, 처음 쓰는 사람은 헤매요. 그 차이를 아는 게 제품 감각이에요.

### 8회 발표회와 앞으로
- **목표** 3분 발표로 문제 → 해결 → 배운 점을 전달한다.
- **발표 틀** ① 어떤 불편이 있었나 ② 이렇게 만들었다(시연) ③ 가장 막혔던 순간과 해결 ④ 다음에 더 하고 싶은 것
- **AI 윤리와 안전 정리** 개인정보를 넣지 않기, 비밀번호·API 키를 코드에 쓰지 않기, 남의 작품·이미지 출처 지키기, 과제를 AI에게 통째로 맡기지 않기.
- **마무리** 수료증과 각자의 사이트 링크 모음 페이지 공개 (본인·보호자 동의를 받은 작품만).

## 🧭 수업 운영 원칙

1. **말하기 70, 듣기 30.** 강사가 설명하는 시간을 줄이고 손을 움직이는 시간을 늘려요.
2. **막힘은 환영.** 에러 메시지를 클로드에게 그대로 보여 주고 같이 읽는 과정이 곧 수업이에요.
3. **작게 시키고, 바로 돌려 보기.** 한 번에 한 기능.
4. **AI는 도구, 책임은 사람.** 결과물에 대한 판단과 책임은 학생에게 있다는 걸 반복해서 말해요.
5. **실패 공유 시간.** 매 회 마지막 5분은 "오늘 가장 이상했던 AI의 답" 발표.

## ✅ 평가 (점수 없이)

- 포트폴리오: 8회 동안 만든 결과물과 링크
- 성장 체크리스트: 지시를 구체적으로 쓸 수 있다 / 결과를 직접 확인한다 / 막혔을 때 상황을 설명할 수 있다 / 내 작품을 남에게 설명할 수 있다
- 동료 피드백 카드 (좋았던 점 1, 궁금한 점 1)

## ⚠️ 시작 전에 꼭 확인할 것

- **계정과 연령 정책.** Claude는 이용 약관상 **만 18세 이상**이 개인 계정으로 쓰도록 되어 있어요. 청소년 대상 수업은 개인 계정을 만들게 하면 안 되고, 기관(학원·학교)이 약관에 맞는 방식으로 운영하는지 **Anthropic 정책과 문의 채널에서 먼저 확인**해야 해요. 이 부분이 정리되기 전에는 신청을 받지 않는 걸 권해요.
- **보호자 동의.** 수업 참여, 작품 공개, 사진 촬영 동의서를 따로 받아요.
- **비용.** 사용량에 따라 비용이 생겨요. 학생 수 × 회차로 예산을 미리 잡고, 사용 한도를 설정하세요.
- **권한 설정.** 모든 허용을 자동으로 넘기는 모드는 쓰지 않고, 기본 모드에서 학생이 직접 읽고 승인하게 해요.
- **장비.** 학생 노트북에 도구를 미리 설치해 두거나, 1회차 앞 30분을 설치 시간으로 잡아요.
